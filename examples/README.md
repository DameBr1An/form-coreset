# Examples

Planned examples:

- `search-results/` — 100 downloaded character images, mixed distractors,
  same-form variants with different backgrounds.
- `lora-dataset/` — image + caption pairs with a per-form cap and a report.
- `objects/` — product/object images grouped by viewpoint/state.

Each example will include a small redistributable sample, expected output, and
the exact CLI command. Status: pre-alpha; examples land after the M0 spike.
